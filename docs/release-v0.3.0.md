# DevDock v0.3.0

## 新增功能

- **后端项目与 SCM**：扫描管理子仓库，登录 SCM、搜索项目，自动同步开发与测试分支；集中展示本地分支，支持点击复制。
- **批量 Git 操作**：切换开发、测试或 master 分支，推送开发分支，使用独立 worktree 合并到测试分支；执行前预检并确认，可选择在 pom.xml 冲突时保留测试版本。
- **公共 Node.js 环境**：支持终端默认、nvm/nvm-windows 和 fnm，在偏好设置统一配置，项目单独选择版本。
- **环境体检与构建历史**：检查项目环境，持久保存构建结果与产物入口，支持设置历史保留条数。

## 优化与修复

- 修复 SCM 项目列表不完整，优化登录会话复用；未填写测试项目 ID 时不再沿用旧测试分支，也不允许测试切换或合并。
- 精简项目编辑与仓库布局，优化分支配色、长名称展示和操作记录。
- 自动检测包含 Node 环境，开发工具与终端命令均提供保存入口；JSON 导出默认定位下载目录。
- 重配五套低饱和度主题，保留深海蓝；优化 macOS 辅助功能授权后的重试体验。

## 安装

- Windows x64：下载 `.exe`；macOS Intel / Apple Silicon：下载通用版 `.dmg`。
- Windows 暂不支持 HBuilderX 自动化及 APK/WGT 构建。Windows 安装包未签名，macOS 未包含 Apple 公证。
